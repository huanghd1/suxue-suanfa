# 数学下潜 · Abyss

一个纯 Canvas 手写渲染的交互式数学长页：从海平面出发，向下潜是主干数学（初中 → 大学 → 研究生 → 研究型），向上飞是非主干延伸（复数、点差法、不动点、放缩…）。

- **向下**：58 关主干推导，深海从浅蓝到全黑，水母被手电照亮才会现身
- **向上**：18 关选学/延伸内容，天空从海面蓝到太空黑，云层随高度稀薄、星星浮现
- **左侧**：知识点目录，点任意一条直接跳到那一关
- **右侧**：随知识点切换的 3D 线框图解（30 种几何体，纯透视投影手算，无任何库），点击标尺也能跳转

## 在线访问

https://huanghd1.github.io/suxue-suanfa/

手机可直接打开：竖屏下自动隐藏左栏与 3D 视口，推导正文铺满宽度；手指滑动即跟随手电。

## 用法

- 打开即停在海平面（画面等于深海上端）
- 向上滚 → 天空，向下滚 → 深海
- 桌面端鼠标移动 = 手电筒，光照到水母会点亮并计数
- URL 参数：`?d=0.42` 锁定海洋深度，`?s=0.62` 锁定天空高度

## 技术

- 单文件 HTML，零依赖、零外部资源、零构建
- Canvas 2D 双缓冲：场景层 + 黑暗遮罩层（`destination-out` 挖洞做手电）
- 3D 视口自写透视管线：绕 Y → 绕 X 旋转 → 透视除法，按深度衰减亮度
- 图形全部程序化生成，没有一张图片、没有一个模型
